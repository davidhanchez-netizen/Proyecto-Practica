# Proyecto-Practica

## Análisis de la página web

### Página analizada
Swag Labs - SauceDemo

### Elementos principales

- Encabezado con el nombre "Swag Labs".
- Formulario de inicio de sesión.
- Campo para ingresar Username.
- Campo para ingresar Password.
- Botón "Login".
- Diseño centrado y sencillo.
- Colores principales: verde, blanco y tonos oscuros.
- La página muestra los usuarios disponibles para realizar pruebas.
- La contraseña indicada es `secret_sauce`.

### Objetivo del proyecto

El objetivo es analizar la página original y posteriormente crear una versión propia
utilizando HTML, CSS y JavaScript, tratando de reproducir su estructura y apariencia.

### Elementos que se deben reproducir

1. Página de inicio de sesión.
2. Campo de usuario.
3. Campo de contraseña.
4. Botón de Login.
5. Diseño visual similar al original.
6. Validación básica del formulario.
